## 0.2.2 — 2026-10-09

0.2.1 之后的版本：干员的潜能和自持有加成改为在「干员调配」里按干员自己设置（默认满潜、精英2 60 级）；新增日文语音、点选干员的语音和本机统计数据页；按官方数据和 PRTS 修正了一大批规则（被推拉的敌人进入失衡、首领场传送门、杜宾「教鞭」三选一、突袭会跳到隐匿敌人身边等），并修复了社区和 GitHub 上反馈的问题、移植了多位贡献者的 PR。战斗模拟改用与浏览器无关的数学函数，各浏览器和服务器的战斗结果逐位一致。规则对照官方数据和 PRTS 核对，详见 DESIGN §27（[docs/history/0.2.2.md](docs/history/0.2.2.md)）；有意和官方不同的写在「有意与官方不同的调整」里。

### 新功能

- 潜能和自持有加成按官方改成每名干员自己设置：「干员调配」里每名干员（普通、精锐和自选共用）可以设潜能 1–6 和练度（未精英化 / 精英阶段1 / 精英阶段2 / 精英阶段2-60级），默认潜能 6、精英阶段2-60级（维护者 2026-10-08 的决定：默认满潜满加成）。潜能和官方一样改变部署费用、再部署时间、属性和天赋（召唤物的天赋按召唤者的潜能）；练度是调度手册「加成情况」里的自持有加成，攻击、防御、生命上限单独乘算，不和其他加成相加（精英1 攻击、防御 ×1.05；精英2 攻击 ×1.1、防御和生命 ×1.05；精英2 60 级三项 ×1.1）。官方中未持有的特许干员按潜能 1、没有加成，想照官方打可以把它设成潜能 1、未精英化；补位的替补干员和自选的原型干员两样都没有，AI 队友按默认。因为默认带满加成，持有的干员的攻击、防御和生命上限都比 0.2.1 高 10%（0.2.1 是全体满潜、没有自持有加成）。设置随调配同步，服务器会校验；旧的调配存档照常可用，没设的按默认；商店卡片、详情卡、「局内数值」和队友的干员都按各自主人的设置显示（GitHub #252）。
- 战场上的场地装置也能点一下看说明了：阻隔工事、“双眼皮”炮台、射击台、源石流发生装置，说明卡的样子和点特殊地形一样；数值取自所在关卡的装置数据（炮台还列出生命、攻击、防御、攻击间隔，吹风装置列出吹风方向和对干员攻击力、敌人移动速度的加减），装置名称按当前语言显示官方译名；作战中阻隔工事和炮台的说明卡带实时血量，被摧毁后点不出来，还没启用的炮台和被机变卡移除的箱子也不显示（GitHub #228，PR #229，感谢 @rickylxw）。
- 大厅和房间的顶栏里，「玩法说明」左边多了一个「设置」按钮，在等待时也能调语言、音量和快捷键等，打开的就是标题画面和对局里的同一个设置窗口。后台播放音乐和棋盘风格选项暂不做（GitHub #238，感谢 @RushFTK）。
- 点选干员时会说官方的「选中干员」语音了：休整期在作战区、整备区点干员，或点商店、晋升奖励里的干员卡片都会说（此前只有作战中才说）；连续点选时新的一句接替正在说的那句，作战中也不会打断部署、技能等更重要的语音。部署、技能、接敌和结算语音仍只在作战中播放；替补干员、原型干员、盟约·辅助干员和召唤物没有官方语音（维护者 2026-10-08 的要求）。
- 新增日文干员语音：「设置」里多了「语音语言」，可选 中文 / 日本語（默认中文，与界面语言无关）。全部 191 名有官方语音的干员都有日文的作战语音（和中文同样的 14 句：行动出发、行动开始、选中、部署、作战中 1–4、结算），个别缺失的句子播中文。完整包附带中文、日文两套语音（因此比 0.2.1 大约 76 MB，约 505 MB）；精简包和源码由 setup 一并下载（日文约 85 MB，素材合计约 550 MB）（维护者 2026-10-08 的要求；GitHub #256 提出的多语种语音先做日文，感谢 @xcdoge）。
- 新增「统计数据」页：标题画面右上角、大厅和等待室顶栏的「统计」打开这台设备上的对局记录——总览（胜场、胜率、到达 / 通关隐秘核心、最远回合、累计时长、各难度、六种称号各拿过几次）、策略（每个策略用了几局、通过几局、通过率）、战斗累计、对局记录（每局一行，点一行回看那一局的结算页，最新的 30 局可以回看）。记录只存在本机浏览器里、不上传，服务器仍然不保存任何历史；最多保留最近 1000 局（约 0.8 MB），可以「导出」「导入」换设备，同盟对局里队友的代号也会存在本机（页面和玩法指南 §12 都写明了）；读不出来的存档会另存为备份后重新开始。打到结算的对局，以及「放弃模拟」前至少清完 1 个回合的对局计入统计；进去就退、没清完第一个回合的对局不计入，但会留在对局记录里并标着「中途退出」和「不计入统计」（维护者 2026-10-08 的要求；GitHub PR #323，感谢 @2321Robin）。
- 「干员调配」的干员列表改成一张表：每名干员一行，技能、模组（精锐）、潜能 · 练度各占一列、上下对齐，直接点行里的技能或模组图标就能换（「不装备」在最前），不用先打开详情；点头像或名字在右边打开详情，最上面是潜能与练度，接着是这名干员的特质（与局内详情卡同一块，跟着普通 / 精锐切换）。宽度 1000 像素以下（如横屏手机）详情盖住列表，点「干员列表」返回；自选编队里持有的干员在名额卡片上设潜能与练度。快捷选择和特质预览来自 PR #301，布局改成一张表，不用三列竖排的卡片（维护者觉得三列竖排有点乱）（PR #301，感谢 @farridge）。
- 点开场上干员的详情卡时，棋盘上会画出它当前的攻击范围：休整期是自己作战区的干员（按携带的技能、模组或替补和朝向）；作战中和查看队友阵地时，我方干员和召唤物（包括队友的）按此刻的位置、朝向和技能画出实际攻击范围（例如开着扩大攻击范围的技能时就是扩大后的范围）；敌人、倒下的干员和整备区里的单位不画，拖动、选朝向时也不画。只显示实际的攻击范围，不做技能范围预测（GitHub PR #281，感谢 @IceCodeNew；范围显示的思路来自 @BBleae）。
- 合作房间新增「AI 队友最后选择」（默认关闭；关闭时选顺与随机不变）。（PR #368，感谢 @anAtheist987）
- 休整期双击队友头像即可查看其战场，「前往查看」仍在；没有战场时不强制打开，正在查看时单击不再重新打开。（PR #374，感谢 @shadiaojumao-hyb）
- 设置新增「问题反馈」，在本地复制诊断信息（可附上本场战斗）；玩家名只替换完整名字和完全相同的 JSON 字符串。（PR #321，感谢 @Cloudnyco）

### 有意与官方不同的调整

- 琳琅诗怀雅二技能的香槟炸弹不再掉血（站在活性源石上、受到各种伤害都不会）、不会被治疗，也不会因为生命值归零而消失，只在「见面礼」炸到碰到它的第一个地面敌人后消失。官方的香槟炸弹会掉血（PRTS：即使自身生命值未满，模型下方也不会显示生命值槽），这是维护者 2026-10-08 的决定。

### 规则（按官方）

- 「同名效果取最高」的效果（减防、脆弱、虚弱、庇护等）有三个或更多同时叠在一起时，最强的结束后按强度依次接上还没到期的那一个，不再跳过中间那一档：例如先后挂上 30%、25%、20% 减防（各 5 秒），30% 结束时接上 25%，再接 20%（此前直接跳到 20%）（GitHub #342，PR #348，感谢 @siruimei07）。
- 圣约送葬人、隐德来希的模组（REA-Y）「攻击范围内存在2名及以上敌人时攻击速度+12」改由战斗引擎统一处理：范围内敌人达到 2 名的那一刻生效、少于 2 名的那一刻消失（此前最多晚约 0.2 秒生效、多留约 0.3 秒）；对全部棋子、补位和自选组合的扫描确认，其他干员不会因此多出攻速（PR #293，感谢 @LimitlessHPPK）。
- 异客三技能的雷暴区域改为以目标所在格为中心的十三格菱形（官方 x-1 范围；PRTS 备注），此前是以目标位置为圆心、半径 1.5 格的圆：目标所在格上下左右第二格的敌人现在也会被雷暴劈中，斜向第二格之外的则不会（GitHub #322，PR #329，感谢 @IceCodeNew）。
- 歌蕾蒂娅三技能结束时的「捕网」只拖拽龙卷风中心 1 格内的敌人（PRTS 备注：捕网半径 1），此前沿用龙卷风的 1.5 格；龙卷风的减速和拖拽仍是 1.5 格（GitHub #324，PR #329，感谢 @IceCodeNew）。
- 信仰搅拌机一技能的补弹对象改为周围 8 格内最后部署的那名开着弹药类技能的拉特兰干员（PRTS 备注；重新部署也算最后部署），此前选离他最近的（GitHub #325，PR #329，感谢 @IceCodeNew）。
- 最终攻势和隐秘核心的领袖战场，传送门按官方会传送了：敌人沿路线走进场边角落的传送门入口时，不再当场算漏怪、扣目标生命值，而是在传送门里消失 3 秒（与数据里写明的传送一样）后从场地中央的传送出口出来，再走向入口这一侧的蓝门，走进蓝门才算漏怪；另有 4 条官方路线漏写了「出现」，敌人穿过传送门后会在出口现身，不再隐身走完剩下的路。被传回来的敌人会再经过一次防线，领袖战的战况随之变化（GitHub #336，PR #337，感谢 @2321Robin）。
- 隐秘核心「假想敌：铳」的【末日布道】：碎铳之簧追到铳身边后不再马上结束追逐，而是在 5 秒增益期间一直跟着铳移动（期间无敌、不攻击），与 PRTS 一致；场上已经没有铳时原地等增益结束。双人战场的两把铳仍各按数据的冷却施放（出场 20 秒后一次，之后每 45 秒），后喊的那把会把所有碎铳之簧叫到自己身边（PR #347，感谢 @CXUtk）。
- 策略「大帝」的加急调派不再有 20 层上限：干员每次部署后再部署时间减少 50%，第 21 次及以后的部署仍会继续减半（PRTS：该策略效果可无限叠加）（GitHub #328，PR #329，感谢 @IceCodeNew）。
- 假想敌「骨刺」按 PRTS 天赋索敌：普通攻击索敌不受阻挡影响（被阻挡后按仇恨优先级选目标，不再先打阻挡者）、不会攻击飞行单位，隐匿期间同时攻击的 3 个目标从普通攻击的范围（含干员碰撞体积）里选（GitHub #296，PR #365，感谢 @Sukvii）。
- 顶栏中间的胶囊按官方口径计数：显示「已解决 / 本回合敌人数」，打死一个、漏掉一个都算已解决（开局 0/3，漏一个 1/3，打死一个 2/3，打死会分裂的那只 3/3）；分裂出来的小怪、召唤物（包括领袖召唤的敌人）不进分子也不进分母，所以会召唤的领袖关胶囊也能填满，不会再因为小怪越分越多而「永远差一截」；它们漏掉时仍然各自扣目标生命值、破坏完美作战，击杀统计和悬赏也照旧（4 只磨砻被打死、分裂出的 8 只全漏：胶囊 4/4，扣 8 点）。队友进度和观战里的胶囊同样按这个口径（PR #308，即 PR #157 的胶囊部分，感谢 @xcdoge）。
- 白铁的「铁钳号·原型机」在干员的攻击范围或技能范围内时，能作用到它的技能会像遇到敌人一样自动开启并消耗弹药：例如范围内只有铁钳号时，圣约送葬人二技能会开启、子弹打在铁钳号上，「每消耗7发子弹」的拉特兰、远见特质照常叠层（此前技能从不开启，子弹和层数都不动）；蕾缪安三技能会锁定它并打完子弹，艾丽妮三技能、陈二技能会斩它，引星棘刺二技能的炼金单元会落在它身上。效果只会挑选敌人、打不到它的技能（如德克萨斯「剑雨」）和治疗技能不会为它开启，留给真正的敌人；白铁™多功能平台仍不会被攻击（社区反馈；维护者 2026-10-08 按官方体验确认）。
- 伊内丝三技能「独影归途」在突袭再部署落地后重新发动（攻击力提升、收回影哨），不再在跳跃后被吞掉；有技力消耗的技能仍按「保留技力」保留原有技力（社区反馈）。
- 引星棘刺一、二技能的炼金单元给友军的生命恢复改为提高「生命回复速度」，与锡人「大拉里」相同（PRTS 锡人备注：不受治疗加成和禁疗影响）：不屈者（如折桠）和处于禁疗的干员现在也能回血，治疗量加成不再放大它（社区反馈）。
- 炎佑是飞行单位，标注「不可对空」的敌人效果不再打到它：高能源石虫、冰爆源石虫、卷心籽的死亡爆炸，水遁忍者的漩涡，鼎沸的范围伤害，“萨科塔昂首”的祈祷邀约（攻击速度 −30），以及“斩胄之剑”“破胄之锤”的攻击（社区反馈）。
- 望放在棋盘上的棋子在开战部署时就由第一天赋「铸子」在相邻格额外部署一枚棋子（跟子），可以落在不可部署的地面上，位置按 PRTS 的顺序（有敌人的格子优先；不可部署地块 > 可部署地面 > 可部署高台；同级按棋子的上 > 右 > 下 > 左）；之后有单位部署到跟子所在的格子时跟子消失；三技能开启时溢出的跟子也按同样的顺序落位。此前开战时一枚跟子都没有，单独一枚棋子永远不会触发（社区反馈）。
- 升级调度中心时，新增的商品栏位立刻出现但保持空着，不再立即刷出一名干员（官方录屏：升级只开位，新位在下一次刷新——手动刷新或回合开始的自动刷新——时才会出现干员），已有的卡片不变；商店里的空栏位只画一个空框，不再写成「已招募」。0.2.0 起「升级立即补一张新卡」的做法撤回（GitHub #332，PR #333，感谢 @2321Robin）。
- 耀骑士临光的特质给自己和身前一格干员的「【卡西米尔】每叠加 3 层，再部署时间 -1.5%（精锐 -3%）」不再在基础值的 5% 处封顶：此前卡西米尔层数很高时（普通 192 层、精锐 96 层起）再部署时间停在 5%，现在按数据一直减到 0 秒为止（GitHub #370，感谢 @FrogThai）。
- 战场#08(下半) 涨潮控制的领袖战：巡逻的「假想敌：铳」和卢西恩从场地中央走向蓝门一侧时走上方的路（与官方寻路一致），不再从下方穿过两格深水区。敌人「优先走能被阻挡的路」的寻路调整现在只在不会多踩深水区时生效，其他战场已有的路线不变（GitHub #375，感谢 @FrogThai）。
- 立即生效、本身不是一次攻击的技能（如引星棘刺「度算浪波」、先锋的回费技能）两次释放之间至少隔一个攻击间隔（释放本身不占用普通攻击）：攻速越快放得越勤，迅捷返还的技力再多也不会每一帧都放（此前迅捷叠高后度算浪波每帧都放，攻速不起作用）（GitHub #298，感谢 @FrogThai）。
- 琳琅诗怀雅二技能的香槟炸弹不会再被没有破隐的隐匿敌人触发：隐匿的敌人被反隐或被阻挡后才会引爆它，沉睡中的敌人醒来后才会引爆它（PRTS：隐匿使单位无法被任何敌方能力选中；此前隐匿、沉睡的敌人走上去照样引爆，沉睡时炸弹白白浪费）（社区反馈）。
- 帝国炮火先兆者、帝国炮火中枢先兆者的炮弹：干员的碰撞体积（半径 0.25）碰到半径 1.2 的落点圆就会受到伤害，也就是落点格和周围一圈共 3×3 格，此前只打中十字形的 5 格（PRTS：碰撞判定；GitHub #364，感谢 @FrogThai）。

### 编辑器有了自己的双击入口

业主复核时问的：「我的一键启动编辑器的脚本呢，游戏脚本自然就有了啊」。确实没有 —— 游戏有 `scripts/start-windows.bat` 与整合包里的 `启动游戏.bat`，而编辑器只有 `npm run editor`。本仓库是 Forge，编辑器就是产品本身，它反倒没有入口，这是个说不通的缺口。

- **仓库**：`scripts/start-editor-windows.bat`（Windows，双击即可）与 `scripts/start-editor.sh`（macOS / Linux）。查 Node ≥ 22 → 首次自动 `npm ci` → `node tools/workshop-editor.mjs --open`。编辑器不碰素材，所以**不需要 setup、也不需要先开游戏服务器**。
- **整合包**：包根多一个 **`启动编辑器.bat`**，与 `启动游戏.bat` 并列；包内说明新增「工坊编辑器」一节（默认只绑 `127.0.0.1:3311`、只写 `app\workshop\**` 与 `app\data\support.json`、保存后要重启游戏服务器、不必开游戏服务器、不需要素材）。
- 两个 `.bat` 由导出的纯函数 `bundleLaunchers()` 生成，测试直接盯住命令体与 `bat()` 里 `%NODE%` 的解析。

### 角色语音台词：接口就位，默认关闭

干员的语音台词（`voice_cn/*`）此前一个文件都没有，客户端也没有播放路径。这一版把**接口**做完整，语音本身仍是可选下载 —— 不加开关时这个仓库与从前一字不差：不下载、不写清单、客户端不请求。

```bash
node tools/fetch-assets.mjs --voices     # 约 2000 段 / 约 138 MB；索引 charword_table.json 只在这时才下载
```

- **清单形状**：`audio.voice[charId][slot] = [url, …]`（数组，因为同一时刻官方有多段录音），槽位 `start` / `select` / `deploy` / `battle` / `win` / `lose`。映射按 `voiceTitle` 建：真索引 18237 条的 `voiceType` **全是 `ONLY_TEXT`**，不带任何分组；研究笔记里那条 `[ASSUMED]`（cn_021/022 选中干员、cn_023/024 部署、cn_025–028 作战中）由此变成已确认。交谈 / 闲置 / 干员报到等不进清单。
