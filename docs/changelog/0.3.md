## 0.3.1 — 2026-10-07

补丁版，只做一件事：把**编辑器 3D 预览全黑**这个静默 bug 修掉，并让地图页**默认就用 3D**。0.3.0 的整合包资产在发布后已被就地替换为含此修复的构建，这一版是把它正式发一版（仓内版本号、tag 与两个资产都对齐）。

### 编辑器 3D 预览「点开全黑」

业主实测报的：「我本地测试点 3D 会全黑，这很奇怪」。用无头 Edge 真跑一遍就复现了，读数很干净：`frames: 0`、`geometries: 0`、画布 10 KB 纯黑，同时控制台两个 404：

```
/assets/local/map/fx/%5Bopt%5Dmerged_textures.png
/assets/local/map/water/%5Bucp%5DTX_water_normal.png
```

根因：编辑器给 3D 预览开的只读素材通路，是拿 `url.pathname`（**保留百分号编码**）直接去查文件的，而官方棋盘图集里正好有两张文件名带方括号的贴图（`map/fx/[opt]merged_textures.png`、`map/water/[ucp]TX_water_normal.png`）。文件明明在磁盘上（9914 / 89085 字节），请求却是 404 —— 棋盘材质缺一块就建不出棋盘，于是**整块画布全黑，而且不报任何错**：页面照样显示「3D 已打开」，提示行里也没有退回 2D 的原因。对照之下游戏服务器对同一条路径返回 200（它会 `decodeURIComponent`），所以这个坑只在编辑器侧。

- 修法：新增 `decodePathSegments()`，**先解码、再按同一套段规则检查**（`..` / `.` / 点开头段 / 空段，解码后出现 `/`、`\`、空字符一律拒）。顺序不能反 —— 先检查后解码会让 `%2e%2e` 骗过 `..` 的判断。四条只读通路（`/client/`、`/vendor/`、`/assets/`、`/docs/`）与语音试听通路都走它。
- 顺带修好同一处的另一个静默失败：**语音包文件名里带空格或 `#` 时，编辑器页面上列得出来、点下去播不了**（页面自己发的试听 URL 就是逐段 `encodeURIComponent` 的）。
- 修复后同一张地图实测：8 次 draw call、4492 个三角形、11 张贴图，画布从 10 KB 纯黑变成 729 KB 有内容。

### 地图页默认进 3D（业主：「2d 地图不直观」）

进一张地图就直接用游戏自己的 3D 渲染器画出来，2D 网格留着当编辑面。

- `?board=2d` 让页面一进去就停在 2D；`?board=3d` 照旧；不带参数 = 默认 3D。
- 作者点按钮切回 2D 之后，自动流程不再把它扳回 3D（按钮和自动逻辑不该互相打架）。
- 挂 3D 之前先取这张地图的推导结果，第一帧就是地图本身而不是空棋盘。
- 没有本机棋盘素材 / 没有 WebGL2 / three.js 没加载时，照旧自动退回 2D 并写明原因 —— 所以这个默认值不会让谁卡在空白画布上。

### 测试

`test/editor.test.js` 新增 4 项：编码后的贴图名必须 200 且与磁盘逐字节相同（没有本机素材的机器跳过）、解码之后仍挡住 6 种穿越写法、语音名带空格与井号能取到、地图页默认 3D 与切回 2D 的规则。全量 **4096 项：4087 通过、0 失败、9 跳过**。

## 0.3.0 — 2026-10-06

本仓库（Forge）的第四个发行版，也是至今最大的一次：创意工坊从「一个内容叠加层」变成**能分享、能自足、能一键试玩**的东西，角色语音从「接口就位、默认关闭」变成**真的会在对局里说话**。游戏本体的规则与数值没有动：下面每一条都属于本项目新增的部分（README「上游来源与修改说明」的 A / C 区）。

### 一、工坊包自带语音，客户端一行都没改

- `pack.json.voices`：`{ "<干员id>": { "<槽位>": ["<assets 内路径>", …] } }`，槽位是 `start` / `select` / `deploy` / `battle` / `win` / `lose`（`shared/constants.js` 的唯一词表，客户端、资产管线、校验器共用）。
- **送达方式刻意不新增客户端通道**：装载时叠加层把各包的台词汇进 `assets.audio.voice`（`shared/workshop.js` 的 `workshopVoiceIndex` / `mergeWorkshopVoices`），游戏服务器再把 `data/assets.json` **合并后**发给浏览器 —— 也就是 `public/js/audio.js` 本来就在读的那份清单（`installAudio({ getManifest: () => data.get('assets') })`）。官方台词在前、包台词在后，一起参与随机，**不替换**官方语音。
- 有包带语音时 `assets` 进入「被触及的数据文件」集合（`workshopTouchedFiles`）；否则浏览器拿到的还是磁盘上的原版，包里配了音也听不见。
- 生成的 URL 就是既有的素材通道 `/workshop-assets/<包>/<路径>`，**逐段百分号编码** —— 包的文件名里可以有 `#` 或空格（与官方语音那 673 个皮肤变体资产同一个坑）。
- **只带语音的包是合法的包**：`content: []` + `voices`（助战干员配音包的形态）。`content` 与 `voices` 都为空才拒（`EMPTY_PACK`），`loadWorkshop` 也不再丢掉「没有数据文件」的包。
- 安装里没有 `data/assets.json`（没跑过素材管线）时，加载器在启动日志里报告这件事，而不是静默丢弃。

### 二、编辑器第七页：语音（`/voice.html`）

`voices` 不是独立文件而是 `pack.json` 的一个字段，所以这一页**就地编辑 `pack.json`**：干员 × 槽位 × 文件，其余字段的值、键序、两空格缩进与结尾换行都不变，**从不补 `content`**。

- 三条 API：`GET /api/voices[?pack=]`（含包内 `assets/` 真实文件、可选干员 id、加载器对该清单的判定）、`POST /api/packs/<id>/voices`（写一个槽位，空数组即清空）、`DELETE /api/packs/<id>/voices/<charId>/<slot>`（幂等）。
- 规则一个字都不复制：槽位用 `VOICE_SLOTS`，扩展名用 `WORKSHOP_ASSET_TYPES`，写盘前先跑 `normalizePackManifest`。路径不允许绝对/反斜杠/盘符/`.`/`..`/空段/隐藏段，且必须真的存在于 `assets/` 下。
- 新增只读**试听**通路 `GET|HEAD /workshop-assets/<包>/<assets 内路径>`：与游戏同前缀（试听 URL 就是生产 URL）、只服务音频那一半白名单、无目录列表、无遍历。
- 「新增/修改」会被清单校验拦住（保存后整包会被拒就 400）；**「删除」只给警告不拦** —— 一条删不掉的语音比一个被校验器报告的包更糟。

### 三、工坊包自带助战卡池（`pack.json.support`）

此前助战池只有 `data/support.json` 一个来源，所以别人下载你的「助战干员语音包」之后还得自己改服务端数据才能把该干员选进助战 —— 包不自足。

- 包声明 `"support": ["<自己的干员id>", …]`，装载时按**记录自己的阶**加进 `pool`（`workshopSupportEntries` / `mergeWorkshopSupport`）。**阶刻意不写进清单**：`isSupportChess()` 要求 id 出现在它自己那一阶的池子里，手写阶只会得到「写错了没人报错、该干员静默不可选」。
- **只能声明本包自己新增的干员**（`SUPPORT_FOREIGN_OPERATOR`）：卡池是安装方的规则决定，内容包不该改它。记录没有 1–6 的整数 `tier` 记 `SUPPORT_TIER_UNKNOWN`。
- 安装方保留最终决定权：`data/support.json` 写 `"workshop": false` 即忽略所有包的声明（启动日志写明）。
- 被触及的 `support.json` **合并后**发给浏览器（客户端从那里渲染助战选择界面）。

### 四、编辑器第八页：包管理（导出 / 导入 / 助战）

在此之前一个包只能靠手抄目录交给别人。第八页（`/pack.html`）把「分享一个包」做成闭环，CLI 与页面走**同一批函数**（`tools/workshop-pack.mjs`），所以两条路不可能给出不同结论。

- **零依赖 zip**（`shared/zip.js`）：只用 `node:zlib` 加自己的一份 CRC-32。写侧确定性（条目按名字排序、固定 DOS 时间戳、deflate 9、压不动退回 store），同样的内容永远得到同样的字节。读侧把每个长度/偏移都当敌意数据，拒绝 ZIP64 / 加密 / 非 0/8 压缩方法 / 多卷 / 重名 / CRC 不符 / 非法 UTF-8 名字 / 绝对路径 / `..` / 盘符 / 空段（目录条目也照样过名字规则），并封顶 4096 条目 / 单条 32 MiB / 解开总量 64 MiB。
- **装包三步且顺序有意**：解压到 `<workshop>/.pack-import-XXXX/`（同卷）→ 用 `normalizePackManifest` 校验（与加载器同一个函数）→ 整个 rename 进 `workshop/<包id>/`。坏归档、恶意归档、校验不过的包**永远不留半个包**；`--force` 时旧目录先改名、新包就位后才删。
- **导出侧新增一道闸门**：包若超过导入上限（归档字节或解开后总量）直接拒绝导出并说明 —— 否则作者会拿到一个「自己这边一切正常、别人一装就失败」的包。
- 除编辑器外还有两个入口（见 §六）：整合包根拖放 `安装工坊包.bat`，以及 `scripts/install-workshop-pack.bat` / `.sh`。

### 五、一键试玩

包管理页的「启动试玩」起一个**游戏服务器子进程**（挑本机随机空闲端口）、等 `/healthz` 就绪、打开浏览器带 `?playtest=1&difficulty=…` 深链，作者不用开终端、也不用先想清楚工坊目录是哪一个。

- **为什么必须是子进程**：`server/data.js` 的 `getData()` 是进程级单例，同一个进程里「重启」也只会拿到第一次加载的数据；而作者点这个按钮要的正是「改完包 → 重启 → 看到新内容」。
- `server/index.js` 的 `main()` 支持 `SP_WORKSHOP`，让子进程读**编辑器当前的工坊根** —— 编辑器可以用 `--workshop` 指向别处，而游戏服务器默认只认仓库的 `workshop/`；不传这一项，试玩里根本看不到正在编辑的包。
- 三条生命周期规则各有测试：**同时只有一个**（第二次 start 返回 `reused`）、**退出必收尸**（stop / 关编辑器 / 编辑器进程退出都杀子进程）、**失败即回滚**（起不来或 30 s 没就绪就杀进程再抛错）。
- 客户端侧 `?playtest=1`（`public/js/playtestLink.js`，纯函数 + 依赖注入）：进入且在线后自动 `room.create { mode:'solo', difficulty }` → `room.start`，然后从地址栏抹掉参数，刷新不会再开一局。难度用 `DIFFICULTIES` 校验，非法键回落大厅默认 `FUNNY`，绝不把非法键发给服务器。

### 六、整合包现在带官方角色语音，以及拖放装包

- **官方角色语音（实测 1848 个文件 / 45.8 MB）进整合包**：此前不带的理由（客户端没有播放路径，放进去只会占地方）已经不成立。语音文件与 `data/assets.json` 里的 `audio.voice` 映射**必须一起进包** —— 只带文件不带映射，客户端根本不会请求它们；打包脚本据此在包内说明里写明「语音已在包里」，反过来（没抓语音的 checkout）不会出现这句话。素材体积 330 MB → **380 MB**（包体 13 600 个文件 / 554.7 MB）。语音**默认关闭**（设置 → 干员语音 = 0），玩家自己调高才听得见。
- **`安装工坊包.bat`**：把包 `.zip` 拖到它上面即装好（`%*` 透传路径；没拖文件时空参数交给 CLI，由 CLI 用中文说明用法并以 2 退出，`bat()` 的「非 0 就暂停」把窗口停住）。命令体保持纯 ASCII —— `bat()` 以 latin1 写出，混中文最容易变成乱码，这条现在有测试钉住。

### 一并修正

- **编辑器 3D 预览「点开全黑」（业主实测发现）**：编辑器的只读素材通路拿 `url.pathname` 里**未解码**的百分号串直接去查文件，于是官方棋盘图集里两张文件名带方括号的贴图 —— `map/fx/[opt]merged_textures.png`、`map/water/[ucp]TX_water_normal.png` —— 请求成 `%5Bopt%5D…` 后一律 404。棋盘材质缺一块就建不出棋盘，**整块画布全黑，而且不报任何错**（页面还显示 3D 已打开）。现在**先解码、再按同一套段规则检查**（`..` / 路径分隔符 / 点开头段 / 空段），编辑器与游戏服务器对同一路径的响应已逐字节一致；同一条修复也救了「语音包文件名带空格或 `#` 时，页面上列得出来、点下去播不了」。三个回归测试钉住它：编码后的贴图名 200、解码之后仍挡住穿越、语音名带空格与井号能取到。
- **编辑器地图页默认打开 3D 预览**（业主：「2d 地图不直观」）：进一张地图就直接用游戏自己的 3D 渲染器画出来，2D 网格留着当编辑面；工具栏按钮随时切回 2D，切回之后自动流程不再扳回来；`?board=2d` 可让页面一进去就停在 2D（`?board=3d` 仍照旧）。没有本机棋盘素材 / 没有 WebGL2 时照旧自动退回 2D 并写明原因，所以这个默认值不会让谁卡在空白画布上。
- **语音下载此前是坏的（而且坏得无声）**：`voiceUrl` 多拼了一层 `sound_beta_2/`（base `RAW.aa2voice` 自己就以它结尾），于是 2002 条语音 URL **全部** 404 —— 清单照生成、客户端照请求、游戏里就是没有人说话。当时的测试自己拼了一个「到 `…/audio` 为止」的 base，期望值恰好跟着错的实现一起错了；现在测试直接用 `RAW.aa2voice`，并断言 URL 里 `sound_beta_2/` **恰好出现一次**，这类重复不能再混过去。修好后实测：1848 个文件（其余 154 条是上游 `voice/` 分支本来就没有的第 3/4 条录音，`assets-report.json` 记为非必需 miss），总量 45.8 MB —— 文档里此前写的「约 138 MB」也是按每名干员 1 MB 拍的估值，这一版一并改成实测值。
- 语音路径校验拒绝 `.` 段（素材路由本来就会 404，早一点报出来更好）。
- `workshopSummary` 显示每个包带来多少条语音、多少个助战声明（启动日志可见）。
- `tools/workshop-validate.mjs` 新增语音层（文件是否存在、扩展名是否可服务、干员 id 是否存在）与助战层（复用同一条 shared 规则），并打印条数。
- `shared/zip.js` 曾被我的一次提交（`1d3e48a`）在共享工作树里用 `git add -A` 误带进仓库（并行 agent 的半成品）；本条一并带上它之后的修正：目录条目也校验名字、本地头名字必须与中央目录一致（`ZIP_NAME_MISMATCH`）、删掉死代码。
