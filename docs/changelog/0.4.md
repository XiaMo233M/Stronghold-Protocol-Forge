## 0.4.2 — 2026-10-07

继续打磨出怪设计器 —— 这一版动的是作者每天都要做的动作。游戏本体仍然没动（上游 0.1.3）。

### 出怪页的路线画布终于有真实地形

作者的活是「在这张图上安排怪从哪走到哪」，而画布此前只有一张空网格：路线定义在地图页、引用在出怪页，
坐标只能对着另一页肉眼抄 —— 抄错一格就是「怪从墙里出来」这种极难查的问题。

- 现在画的是**选中地图的真实地形**（官方 11 张图与工坊地图都带 `rows`/`tiles`），地图自己画的装置也标出来。
- 取色两档：调色板认识的字用它的颜色；**不认识的按该图图例里的高度给近似色**。第二档是必需的 ——
  官方地图会用到调色板之外的地形（`A` = `tile_achand`，11 张图里 165 格），只按调色板取色会留下一片黑洞，
  看不出那是高台还是墙。实测官方地图每一格都能被这两档覆盖，测试里钉住了「零遗漏」。
- 页头把状态说清楚：「官方地图 · 底图：切尔诺伯格」或「这张地图没有地形数据，只画网格」——
  画布上看到的到底是什么，不该让作者猜。

### 敌人下拉：从 250 项平铺改成按来源分组 + 中文名

官方 249 只怪共用一堆 `enemy_10xx_yyyy` 这种键，作者记不住；250 项、只有键名的原生下拉基本没法用
（中文还得靠输入法逐字匹配）。现在按 `官方` / `本包：<包>` 分组，选项显示 `名称 (key)`，
阵营占位符的标注照旧跟在后面。

### 缺怪时可以一键跳去新建

以前中途发现缺一只怪要：先保存出怪表（否则切页就丢）→ 切页 → 新建 → 保存 → 切回来 → 重新载入 →
重新打开这张表 → 再选那只怪。现在下拉第一项就是「＋ 新建怪物…（新标签页打开）」：

- **必须新标签页**：这张出怪表还没保存，把本页顶掉就等于把作者的工作丢了（测试专门钉住这一条）。
- 顺手带上当前包（`enemy.html?pack=<包>`），怪物编辑器认得它，跳过去就能直接在那个包里新建。
- 新标签页被拦下时给一句人话：手动打开、回来点「重新载入」就能选到。

### 顺带补齐两个页面的运行时测试

地图页与出怪页此前只有源码断言。这两轮刚给它们加了回合绑定、底图、占位符提示 —— 这些地方一旦写错，
用户看到的是「页面一片空白」，源码断言抓不住。现在两页各有一条最小 DOM 桩的**真跑走查**：

- 出怪页：真的去点新建出怪表、添加一次出怪，断言画布上**真的画出了地形**（按 2D 上下文的调用记录核对颜色与格子数）。
- 地图页：打开一张地图，改一个回合的绑定，然后去**校验请求体**里核对 `spec.rounds` 真的更新了
  （那正是保存时会发出去的东西）；首领回合写进 `bossRounds` 并带上该模式的首领 id。

### 测试

全量 **4229 项**：4220 通过、0 失败、9 跳过（较 0.4.1 增加 21 项）。

## 0.4.1 — 2026-10-07

0.4.0 之后接着做的三件事，都是「不报错但结果不对」那一类。游戏本体仍然没动（上游 0.1.3）。

### 出怪表终于能真正绑到回合上（地图设计器新增「回合绑定」）

此前作者能做出出怪表，却**没法在界面里让它生效**：真正决定「这一回合出什么怪」的是**地图自己的
`rounds` / `bossRounds`**（引擎先看这张图、再看模式的模板），而地图页不编辑它们；出怪页那个「绑定到回合」
写的是 `usedBy`，引擎从来不读。作者做到最后一步只能手改地图 spec 的 JSON。

- 地图设计器侧栏新增**回合绑定**面板：按这张图勾选的模式列出每个回合，每行都显示「不指定的话本来会打哪张表」
  （不显示这个，作者没法判断该不该覆盖），并给一个出怪表下拉（官方 38 张 + 本包自己的）。
  首领回合再多一行 —— 给该模式的每个首领 id 都写上，抽到谁都走你的表。
- **绑了不存在的 id 会静默回落**到模式的模板，而校验器只查形状（是不是字符串）。所以面板自己查存在性，
  把失效的绑定逐条列出来。
- 出怪页反过来显示**权威的那一半**：「真正在用这张表的地图」直接从地图数据里读，跟上面那份「意图」并列，
  两边对不上时一眼就能看见。
- 顺手修掉一个真会丢数据的 bug：地图页拼 spec 时**没有带上 `rounds`** —— 也就是说「打开一张已经绑好回合的
  地图、随手保存一下」，绑定会被静默删干净。现在原样带上，并且有端到端测试盯着（保存两次、只改名字，绑定都在）。

### 阵营占位符会被标出来

官方 249 只怪里有 8 个键是阵营随机生成的占位符。选了它们，实际出的是阵营随机怪、数量按战力重算；
抽到的怪与它移动方式不同时，这一次**一只都不出**，而校验器一个字都不说。

- 出怪页的敌人下拉把这些键标成「（阵营占位符）」，用了它们时右栏给一条警告。
- 清单由服务端从 `data/factions.json` 的 `templateSlots` 送来 —— **不在编辑器里另抄一份规则表**。

### 保存目标从对话框改成下拉（五个页面）

地图 / 怪物 / 出怪 / 装备 / kit 五个页面此前都用同一句 `window.prompt` 手打「保存到哪个工坊包」，
打错就是存进别的包或凭空建一个空包。现在侧栏常驻一个下拉，列出所有包（id 与 `pack.json` 里的名字）；
只有「＋ 新建一个包…」才问一次 id。

### 测试

全量 **4208 项**：4199 通过、0 失败、9 跳过（较 0.4.0 增加 35 项）。新增的四个文件分别盯住：
回合表的读取/归一化/失效检测/写入与页面接线、接口与保存端到端不丢回合、占位符判定（拿官方真实数据跑）、
以及保存目标下拉的选项与取消行为。

## 0.4.0 — 2026-10-07

这一版只做业主点名的两件事，外加几个我自己挑的小改进：**新建干员/怪物更容易**，以及**编辑器界面中英双语**。
游戏本体一行没动（上游仍是 0.1.3）。

### 双语界面（八个页面全部接入）

- 右上角多了一个 `EN` / `中文` 按钮，选择记在 `localStorage`；也可以用 `?lang=en` 直接给链接。
  **默认中文**。
- 词典以**中文原文为键**：中文界面不需要维护任何对照表，英文只写「中文 → 英文」，
  **缺译文时退回中文**（而不是显示 `pack.newOperator` 这种 key 名，更不是一片空白）。
- HTML 里的静态文案用 `data-i18n`，元素里保留中文原文当兜底：脚本没跑起来时页面是中文。
- 词典按页分片（`i18n.en.shared.js` + `i18n.en.<页>.js`）。规则写进了 shared 的文件头：**两个以上页面共用的词条
  必须放 shared** —— 放在某一页里，那一页收尾时把它当死键删掉，别的页面会悄悄退回中文，而当场没有任何测试发现。
- kit 页是个特例：它有「页面脚本不许 import 任何东西」的安全断言（那一页直接编辑并展示作者的 kit 源码），
  所以走 `i18n.global.js` 把接口挂到 `globalThis`，`kit.js` 保持零 import。
- 测试闸门 `test/editorI18n.test.js` 不只测 API，还扫源码：**前向**（源码里每条中文都译过）、
  **反向**（词典里没有死键）、**卫生**（译文非空、不留中文、分片无重复键、不许把带插值的模板串塞进 `t()`）。
  这套闸门在本次改造中当场抓出了 20 多条漏译、死键与跨页重复键。

### 新建干员更容易

- **以模板新建**：挑一个官方干员（266 个里搜）或复制本包已有干员，数值、职业、分支、**攻击范围**、
  技能（含黑板）、天赋、外观一次填好，只需填新 id 与名字。模板**故意不带 id**（顺手复制会直接撞官方 id）。
- **数值参照尺子**：每个数值下面一条细线，标出官方同职业的 min–中位–max 与当前值落点，越界时变色并写明。
  以前这些数字是凭感觉拍的，而且没有任何东西告诉作者「5 阶狙击」大概该是多少。
- **攻击范围终于有界面**：表单此前**完全没有范围入口**（连默认值是多少都看不到），只能吃默认的近战 2 格 /
  远程 10 格。现在能从官方形状里挑（每种形状标一个用过它的干员当例子，例如「10 格 · 例：能天使」），
  并把当前生效的形状画成小格阵，高亮干员自己那一格。
- **伤害分类可见**：物理/法术/治疗 · 近战/远程 · 能否打空，用的是引擎真正会用的那份推导（`shared/chessAuthoring.js`）。
- **id 冲突立刻提示**：撞本包已有干员、或撞官方 id（不进 overrides 会被引擎丢弃）分别提示。
- **改 id 会提醒**（修一个真 bug）：已有干员改了 id 再保存只会**新建**一份记录，原来那份仍留在包里 ——
  以前既不自动删也不提示，作者会莫名其妙多出一个干员。现在表单里就写明。
- **表单不再丢焦点**：校验是 250ms 防抖自动跑的，每跑一次就重画一次表单，以前会把光标扔掉
  （打一半停下来看一眼、再打字就得重新点）。

### 新建怪物更容易

- **以模板新建**：官方 249 只怪随便挑一只当底子（数值、档位、攻击方式、能力文字、技能、免疫、spine 一次带过来），
  或复制本包已有怪物。
- **spine 有候选、也会当场警告**：这是整张表单里**唯一一个填错不报错**的字段 —— prefab 键查不到时游戏直接画个
  占位菱形，照跑不误。现在输入框挂了官方 prefab 候选，并在下面说清三种情况的后果。
- **数值参照尺子**：按**档位**（普通/精英/领袖）给区间，切到精英怪时尺子跟着换。

### 服务端（编辑器专用，游戏服务器不受影响）

- `GET /api/operators/template?chessId=` 与 `GET /api/enemies/template?key=`：把一对已发布的记录转成一份可继续编辑的 spec。
- `/api/state` 增加 `statRanges`（按职业）；`/api/enemies` 增加 `officialTemplates`、`spineChoices`、`statRanges`（按档位）。
- 编辑器现在也把 `/shared/` 挂给界面（路径校验与其它挂载同一套）：界面与服务端**共用同一份** shared 模块，
  不必在浏览器里抄第二份实现。

### 顺带修掉的两个「复制会悄悄改行为」

模板转换（`specFromChessRecord` / `specFromEnemyRecord`）写完后用**真实数据的往返测试**盯住：转成 spec 再派生回记录，
逐项比对。它当场抓出两处丢失 —— 68 只官方怪的 `rawRangeRadius`（射程）会丢、13 只双属性怪（`['phys','arts']`）
会被 spec 的单值 `dmgType` 吃掉一半。两者都已修：前者原样带上，后者给 spec 加了显式覆盖（不给时行为与以前完全一样）。

### 另外

- 修掉首页 `TRIGGERS` 枚举少一个 `CUSTOM_RANGE` 的问题。后果不是报错，而是：打开一个用了它的已有 spec 时下拉
  显示成 `DEFAULT`，用户随手一改就把人家的原值覆盖掉了。
- **全量测试 4173 项**（较 0.3.1 增加 77 项），新增的测试包括：模板转换的往返一致性、三个新接口端到端、
  双语闸门、以及**两个页面各一条「最小 DOM 桩真跑一遍」**的走查（真的去点新建、选模板、切语言）。
